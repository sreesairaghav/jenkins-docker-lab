Student Management System - CI/CD

A simple web application for managing student information

About the Application

The Student Management System is a web application designed to manage basic student information in one place. It provides a simple interface for viewing and managing student-related details.

Features

Student Details

Store and view basic information about students.

Easy Management

Manage student records through a simple interface.

Web Based

Access the application through a web browser.

Technology Used

This application is deployed using Docker and Nginx. GitHub is used for source code management and Jenkins is used to automate the build and deployment process.
